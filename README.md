# Harichand Steel - Complete Multi-Page Redesign & CMS Dashboard (HTML5, CSS3, JavaScript)

Complete, lightweight, and modern website redesign for **Harichand Steel** ([harichandsteel.com](https://harichandsteel.com/)). Converted from heavy WordPress/Elementor into lightning-fast, zero-dependency **HTML5, CSS3, and vanilla JavaScript (ES6+)** with a full-featured **Admin CMS Dashboard** for managing products, blog posts, and customer leads.

---

## 🚀 Quick Start

### Option 1: Run Local Server (Recommended)
With Node.js installed, run:
```bash
node server.js
```
Then visit:
- **Website Homepage:** [http://localhost:3000/](http://localhost:3000/)
- **CMS Admin Dashboard:** [http://localhost:3000/admin/](http://localhost:3000/admin/)
- **Products Catalog:** [http://localhost:3000/product.html](http://localhost:3000/product.html)
- **News & Articles:** [http://localhost:3000/news.html](http://localhost:3000/news.html)

### Option 2: Offline / Direct Double-Click
You can also open [`admin/index.html`](file:///C:/Users/Lenovo/.gemini/antigravity/scratch/harichand-steel-redesign/admin/index.html) or [`index.html`](file:///C:/Users/Lenovo/.gemini/antigravity/scratch/harichand-steel-redesign/index.html) directly in any browser without running a server. The CMS automatically caches changes in `localStorage`.

## 🛠️ CMS Dashboard Features ([`admin/index.html`](file:///C:/Users/Lenovo/.gemini/antigravity/scratch/harichand-steel-redesign/admin/index.html))

1. **Dashboard Overview**:
   - Total products counter, active blog count, and customer lead counters.
   - Quick Add shortcuts for new products and articles.
   - Recent items activity table.
2. **Product Catalog Manager**:
   - Full CRUD: Add, Edit, Delete, and Preview products.
   - Live Search & Category Filtering (`Aluminum Profile Gate`, `Steel Main Gate`, `Steel Door`, etc.).
   - Support for custom badges, price tags, image URL or instant file upload preview, and technical spec pills.
   - Dynamic real-time sync with [`product.html`](file:///C:/Users/Lenovo/.gemini/antigravity/scratch/harichand-steel-redesign/product.html).
3. **News & Blog Post Manager**:
   - Publish guides, case studies, and local landing announcements.
   - Live Search & Tag Filtering (`Design Guide`, `Manufacturing`, `Case Study`, `Luxury Projects`).
   - Title, slug, author, publish date, cover image preview, excerpt, and full body content.
   - Dynamic real-time sync with [`news.html`](file:///C:/Users/Lenovo/.gemini/antigravity/scratch/harichand-steel-redesign/news.html).
4. **Customer Leads & Inquiries Manager**:
   - Automatically logs quote estimator submissions and contact form requests.
   - One-click WhatsApp reply button for quick client follow-ups.
   - **Export to CSV** for CRM tracking.
5. **Backup & Database Tools**:
   - One-click full JSON backup export.
   - JSON backup restore/import.
   - Reset to default live seed data.

## 🌟 Key Architecture Highlights

1. **Navigation Structure**:
   - `Home` | `Our Products` (single line, no dropdown) | `About us` | `Contact` | `News` | `Product ˇ` (with dropdown).
2. **Local Internal Links**:
   - All internal links point strictly to local `.html` files (or directory mirrors). No redirection to external WordPress URLs.
3. **Zero Dependencies**:
   - No jQuery, no Elementor, no external frameworks. Fast loading, pure CSS3 styling, and standard ES6 vanilla JS.
